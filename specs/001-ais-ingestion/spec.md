# SPEC-001: AIS ingestion, normalization and provenance

**Status:** IMPLEMENTED — synthetic regression tests and one initial real NOAA archive ingestion smoke; event labels unvalidated · **Created:** 2026-11-08; **Updated:** 2026-11-21. Package `0.2.0.dev21` reports expected `harborlens` domain errors through `parser.error`.

## Problem / user story

A researcher needs a source-pinned local AIS batch with reliable input field normalization and explicit quality exclusions.

## Linked requirements

FR-001..004, FR-008; NFR-002..006; BR-002, BR-004..006

## Acceptance criteria

1. **Given** a valid NOAA-style CSV; **when** the CLI runs; **then** normalized UTC observations, bbox and exact-dedup counts, SHA-256 and outputs are generated.
2. **Given** invalid, duplicate and out-of-zone rows; **when** ingest runs; **then** each exclusion type is reported separately and invalid rows do not enter cleaned output.
3. **Given** unsupported or malformed data; **when** a batch is requested; **then** a clear error or rejection is produced; no fabricated event is returned.
4. **Given** a NOAA-style timestamp on Python 3.10 or 3.12; **when** it is parsed; **then** both interpreters accept `YYYY-MM-DD`, an uppercase `T` or one space, `HH:MM:SS`, no fraction or 1 to 6 fractional digits, and an optional `Z` or `±HH:MM`. A missing offset means UTC. A non-UTC offset is converted to UTC. Seven fractional digits, a comma fraction, `+HHMM`, a non-ASCII digit, hour 24, a non-leap 29 February, and trailing junk are rejected on both.
5. **Given** `harborlens-download-noaa --date`; **when** the value is not a real ASCII `YYYY-MM-DD` date, including an ISO week date or `YYYYMMDD`; **then** the command exits 2, writes nothing, and does not open a network connection. 29 February is accepted only in a leap year.
6. **Given** the files `git ls-files` tracks; **when** `tests/test_synthetic_ids.py` runs; **then** no nine-digit token whose first three digits are an MID in 201–775 remains outside a file-exact exclusion or a documented context exclusion (a hexadecimal run of 64 or more characters, or the value assigned by a whole-word `mmap_size`). A run of ten or more digits does not match. Nine digits after a digit and a dot are a decimal fraction and do not match. A dot that is not part of a decimal still matches.
7. **Given** a free-text AIS cell (`vessel_type` or `nav_status`, including a fullwidth trigger or an ignorable character before a trigger) that matches `^'*<ignorable>*<trigger>`; **when** `harborlens` or `harborlens-multiday` writes `houston_clean.csv` or a stationary-candidate CSV; **then** the cell is prefixed with one apostrophe and the reader recovers the logical text by removing exactly one apostrophe only when the cell matches `^'+<ignorable>*<trigger>`. Ignorable characters are the fixed code points in `csv_safe.IGNORABLE`, including U+FEFF, U+200B, U+200C, U+200D, U+200E, U+200F, U+2060–U+2064, U+206A–U+206F, U+00AD, and U+180E. The writer does not consult the Unicode database at runtime. Numeric columns, including a negative longitude, and MMSI are not prefixed. `source_files_json` stays a JSON array. GeoJSON is not neutralized. On `tests/fixtures/synthetic_ais.csv` the three pipeline artifacts stay byte-identical to package `0.2.0.dev15`.
8. **Given** `harborlens-fr-timeline --start` or `--end`; **when** the value is not a real ASCII `YYYY-MM-DD` date, including an ISO week date, `YYYYMMDD`, non-ASCII digits, or an impossible calendar day; **then** the command exits 2, prints the `FederalRegisterAuditError` message, prints no traceback, and does not open a network connection (FR-002, FR-011, NFR-003, NFR-004, NFR-009, NFR-010, NFR-015). Valid dates that also satisfy the window rules in criterion 9 follow the existing scan. This does not approve a berth, anchorage, wait, or port call (BR-009, BR-018).
9. **Given** real ASCII `YYYY-MM-DD` dates that break one publication-window rule; **when** `harborlens-fr-timeline` runs; **then** it exits 2 before any network `Request` is built, stdout is empty, and no output file is written (FR-002, FR-011, NFR-003, NFR-004, NFR-009, NFR-010, NFR-015). `main` calls `_date`, then `validate_publication_window`. The first true rule wins: start after end, start before 1994-01-01, end after today, then a span of more than 370 days. With today frozen at 2026-11-21 the messages are `--start (2024-01-02) is after --end (2023-07-01). Use calendar dates YYYY-MM-DD, with start on or before end, a span of at most 370 days, start in 1994 or later, and end not after today.`, `--start (1993-12-31) is before 1994-01-01, the earliest date this command accepts.`, `--end (2026-11-22) is after today (2026-11-21). Use a historical end date on or before today.`, and `--start and --end span 371 days; the maximum historical publication window is 370 days.`. stderr is the argparse usage line plus that one error line, with no traceback. Today is the UTC date from `_today`. Tests replace it with 2026-11-21. A span of exactly 370 days (`2025-01-01` through `2026-01-06`), start equal to end (`2024-01-02`), end equal to that frozen today, and start equal to 1994-01-01 pass. The default window `2023-07-01` through `2024-01-02` still scans. `initial_url` checks the same rules. `main` catches only `FederalRegisterAuditError`, including an existing output file and a download failure. A bare `ValueError` and `KeyboardInterrupt` still propagate. Package `0.2.0.dev20`. This does not approve a berth, anchorage, wait, or port call (BR-009, BR-018). `--debug` on this command prints a traceback after that error line and still exits 2. Package `0.2.0.dev21` adds the flag. The window rules are unchanged.
10. **Given** `harborlens --input` that is missing, empty, or a CSV whose header lacks a required column; **when** the command runs; **then** it exits 2, stdout is empty, stderr is the argparse usage line plus one `error:` line, and there is no traceback unless `--debug` is set (FR-001, FR-008, NFR-001, NFR-009, BR-001). `--debug` prints the traceback after that line and still exits 2. It does not change a successful run. `--version` and `-V` print `harborlens` and the package version and exit 0 without `--input`. `--help` exits 0 and names NOT FOR NAVIGATION, the output default, the Houston–Galveston box, and the segmentation defaults. A per-row invalid value stays `invalid`. `KeyboardInterrupt` is not caught. An unexpected exception still exits 1 with a traceback. On `tests/fixtures/synthetic_ais.csv` the three pipeline artifacts stay byte-identical to package `0.2.0.dev15`. This does not make a stationary candidate a berth, anchorage, wait, or port call (BR-001).

## Non-goals and safety

No operational navigation, autonomous control, live vessel tracking, regulatory certification, unverified berth or waiting-time claims, or unauthorized licensed data redistribution. A synthetic fixture is not independent validation.

## Definition of Done

Accepted and reviewed requirements, passing boundary/negative tests, documented source rights, updated JSON schema and traceability, explicit uncertainty and reproducible evidence attached to the linked issue/PR.
