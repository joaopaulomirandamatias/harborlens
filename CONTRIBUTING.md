# Contributing to HarborLens

All code, commit messages, GitHub issues and documentation must be written in English.

1. Pick a SPEC-### from `specs/`, or propose a new specification before changing behavior.
2. Link FR/NFR/BR requirement IDs, Given/When/Then acceptance criteria, dependencies and measurable evidence in the GitHub issue.
3. Branch using `feat/SPEC-###-name`, `fix/ISSUE-###-name` or `docs/name` and follow Conventional Commits.
4. Add positive, negative, boundary and regression tests. Run `python -m unittest discover -s tests -v`.
5. Update JSON Schemas, ADRs, traceability and changelog when behavior or contracts change. Bump the package version (`pyproject.toml`, `src/harborlens/__init__.py`, `CITATION.cff`) for any change that can alter outputs: it is part of every `run_id`.
6. Do not commit authentic NOAA AIS, licensed data, private terminals' data, secrets, or third-party IP without explicit rights verification.
7. A reviewer must confirm requirements, tests, license, security, uncertainty claims and documentation before merging.
8. Synthetic vessel identifiers use unassigned MID 199 and the form `1990xxxxx`. Do not commit a nine-digit token whose first three digits are an assigned MID in 201–775, in any tracked text file. The guard reports the union of the raw text and a normalized copy. It removes U+005F between digits, maps the fixed `UNICODE_DIGIT_TO_ASCII` blocks to ASCII, and removes the fixed splitter set U+FEFF, U+200B–U+200F, U+2060–U+2064, U+206A–U+206F, U+00AD, U+180E, U+061C, U+202A–U+202E, U+2066–U+2069, U+034F, U+FE00–U+FE0F, U+E0100–U+E01EF, U+180B–U+180D, U+E0000–U+E007F, U+115F, U+1160, U+3164, U+FFA0, U+2800, U+0301, U+20E3, U+17B4, U+17B5, U+1D173, U+FE20–U+FE2F, and U+FFF9–U+FFFB. It decodes a `\U`, `\u`, or `\x` escape only for a digit, one of those splitters, or U+005F. A decimal fraction (a digit, a dot, then the nine digits), a run of eight digits, and a digit run longer than nine digits are not tokens. A hexadecimal run of exactly 64 characters is a SHA-256 exclusion, including nine digits at either edge. A longer run excludes a nine-digit span only when the span is strictly inside the run. The value assigned by `mmap_size` is a context exclusion only in `tests/multiday_memory_probe.py`, and only when the spacing around `=` is a space or a tab. Each file is the union of a BOM decode, UTF-8 with surrogateescape, and ISO-8859-1. A NUL byte without a UTF-16 or UTF-32 BOM is reason `nul-byte`, and a tracked file in that state fails the guard. The map pins live next to the guard and are not a tamper-proof seal. An Nd digit missing from the fixed table uses `unicodedata.decimal`, and an Nd digit with no decimal value is still a hit. An underscored numeric literal longer than nine digits is a hit when a nine-digit window has an assigned MID. Write that constant without underscores. The eight Unicode 16 digit-block starts are covered on the Python 3.14 CI job when that interpreter classifies them as Nd. Known limits are a Python `0o` or `0x` literal, `chr()`, `int()` built from pieces, adjacent string literals, base64, a hyphen, space, comma, dot, apostrophe, or NBSP inside the nine digits, and file names. File-exact exclusions are the dev9 goldens and `tests/synthetic_id_map.py`, each with a written reason. The map's rule tuple and the assigned-MID tokens in that file are pinned. Do not mint synthetic identifiers with the prefixes `111`, `970`, `972`, `974`, `98`, `99`, or `0xx`. The fixed legacy-to-199 map is `tests/synthetic_id_map.py`. The guard is `tests/test_synthetic_ids.py`. `mmsi_category` classifies a leading `1` as `other`.

**Definition of Done:** Accepted spec linked, tests pass, outputs reproducible, data provenance and rights documented, and no synthetic-only claim is presented as empirically validated.
