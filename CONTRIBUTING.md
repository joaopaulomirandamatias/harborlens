# Contributing to HarborLens

All code, commit messages, GitHub issues and documentation must be written in English.

1. Pick a SPEC-### from `specs/`, or propose a new specification before changing behavior.
2. Link FR/NFR/BR requirement IDs, Given/When/Then acceptance criteria, dependencies and measurable evidence in the GitHub issue.
3. Branch using `feat/SPEC-###-name`, `fix/ISSUE-###-name` or `docs/name` and follow Conventional Commits.
4. Add positive, negative, boundary and regression tests. Run `python -m unittest discover -s tests -v`.
5. Update JSON Schemas, ADRs, traceability and changelog when behavior or contracts change. Bump the package version (`pyproject.toml`, `src/harborlens/__init__.py`, `CITATION.cff`) for any change that can alter outputs: it is part of every `run_id`.
6. Do not commit authentic NOAA AIS, licensed data, private terminals' data, secrets, or third-party IP without explicit rights verification.
7. A reviewer must confirm requirements, tests, license, security, uncertainty claims and documentation before merging.
8. Synthetic vessel identifiers use unassigned MID 199 and the form `1990xxxxx`. Do not commit a nine-digit token whose first three digits are an assigned MID in 201–775, in any tracked text file. The guard removes U+005F between ASCII digits and removes the fixed splitter set U+FEFF, U+200B–U+200F, U+2060–U+2064, U+206A–U+206F, U+00AD, U+180E, U+061C, U+202A–U+202E, and U+2066–U+2069. It decodes a `\u` escape of four hex digits only for an ASCII digit, one of those splitters, or U+005F. A decimal fraction (a digit, a dot, then the nine digits), a run of eight digits, and a digit run longer than nine digits are not tokens. A hexadecimal run of exactly 64 characters is a SHA-256 exclusion, including nine digits at either edge. A longer run excludes a nine-digit span only when the span is strictly inside the run. The value assigned by a whole-word `mmap_size` is a context exclusion only when the spacing around `=` is a space or a tab. A UTF-16 or UTF-32 file with a BOM is scanned. A NUL byte without that BOM is reason `nul-byte`, and a tracked file in that state fails the guard. A non-UTF-8 file with no NUL is scanned. File-exact exclusions are the dev9 goldens and `tests/synthetic_id_map.py`, each with a written reason. The map's rule tuple and the assigned-MID tokens in that file are pinned. Do not mint synthetic identifiers with the prefixes `111`, `970`, `972`, `974`, `98`, `99`, or `0xx`. The fixed legacy-to-199 map is `tests/synthetic_id_map.py`. The guard is `tests/test_synthetic_ids.py`. `mmsi_category` classifies a leading `1` as `other`.

**Definition of Done:** Accepted spec linked, tests pass, outputs reproducible, data provenance and rights documented, and no synthetic-only claim is presented as empirically validated.
