# Canonical Data Dictionary

| Entity | Fields | Meaning |
| --- | --- | --- |
| Clean AIS point | mmsi, timestamp_utc, lat, lon, sog_knots, vessel_type, nav_status, cog_deg, heading_deg, length_m, width_m, draft_m, transceiver_class, mmsi_category | Transmitted observation; not verified vessel identity. NOAA "not available" sentinels (COG 360, heading 511, zero dimensions or draft) become empty cells; `transceiver_class` is `A`, `B` or empty; `mmsi_category` is an ITU-R M.585 QA flag |
| Stationary candidate | event_id, mmsi, start_utc, end_utc, duration_min, point_count, centroid_lon, centroid_lat, maximum_distance_m, type, method_version, parameter_set, confidence_label, left_censoring, right_censoring, vessel_type, transceiver_class, length_m, draft_m, mmsi_category | Low-speed contiguous AIS sequence, not confirmed anchorage or berth. `left_censoring`/`right_censoring` ∈ {censored, not_censored, unknown} (BR-019); `censored` means `duration_min` is a lower bound |
| Run manifest | input_file, input_sha256, bbox_lon_lat, counts, events (split reasons, `discarded_by_reason`, `candidates_per_mmsi`, `censoring` counts), method_parameters (thresholds, `method_version`, `parameter_set`), analysis_window, input_truncated | Provenance and QA counters for current prototype. `analysis_window` records window blocks, how each was declared, internal gaps and the observed time range |
| Source snapshot (planned) | source_id, agency, url, dataset_version, retrieved_at_utc, file_sha256, license_status | Origin and rights for future data lineage |

Time is RFC 3339 UTC; positions are decimal WGS84 degrees with longitude first in GeoJSON; SOG is knots, distance meters, duration minutes. Identifier MMSI is not a stable guaranteed vessel identity. All candidate confidence is **unvalidated** pending expert labeling and official event comparison.

In `stationary_candidates.csv`, `duration_min`, `centroid_lon`, `centroid_lat` and `maximum_distance_m` are decimals and `point_count` is an integer; `harborlens.ais.read_candidates_csv` returns typed records. Manifests carry `code_version` (`package_version`, which is part of `run_id`, and `git_commit` when known from CI).

`method_version` is `stationary-v0.2` for both commands. `parameter_set` is a 12-hex fingerprint of the method version and thresholds; candidate GeoJSON files also carry the full thresholds in a top-level `harborlens_method` member. A threshold-sensitivity report (`schemas/v1/sensitivity-report.schema.json`) lists counts per setting and is descriptive only.

A labeling-sample manifest (`schemas/v1/label-sample.schema.json`, `label-sample-v0.2`) is the blinded-sample key for one verified run. It is not a label and not a verified event. `transceiver_class` on each key item is `A`, `B`, or `absent_or_unknown` (missing, blank, or any other transmitted class). The stratum key ends with that token. `stratification.all_non_empty_strata_drawn` is false when the requested size is smaller than the number of non-empty strata; every class present in the frame is still drawn when the request is at least the number of those classes. The annotator sheet does not include the class. Text cells on that sheet, and free-text AIS cells (`vessel_type`, `nav_status` on the cleaned CSV, `vessel_type` on the candidate CSV), are prefixed with one apostrophe when they match `^'*<ignorable>*<trigger>`. Ignorable characters are the fixed set `harborlens.csv_safe.IGNORABLE`. The reader removes exactly one apostrophe when the cell matches `^'+<ignorable>*<trigger>`. `mmsi`, point counts, coordinates, timestamps, censoring flags, and label enums are validated and are not prefixed. A negative longitude stays a negative longitude. Import the sheet with columns as Text and re-validate it after editing. The key file is JSON. GeoJSON stores the logical `vessel_type` and is not a spreadsheet formula.

Candidate attributes are the first non-empty transmitted ship type and the most frequent non-empty transceiver class, length and draft among the candidate's observations; missing values are `null` in GeoJSON and empty in CSV. `mmsi_category` values: `ship`, `group_of_ships`, `coast_station`, `sar_aircraft`, `aid_to_navigation`, `craft_associated_with_parent_ship`, `handheld_vhf`, `ais_sart`, `mob_device`, `epirb_ais`, `placeholder` (for example `000000000`, `123456789`), `leading_zero_ambiguous` (8-digit values, because NOAA stores MMSI as a number) and `other`. Rows are never dropped because of their category; manifests count accepted points per category (`mmsi_categories`).
