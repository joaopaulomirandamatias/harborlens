# ADR 0003-open-core-boundary: Open reproducible methods, optional commercial managed services

**Status:** Proposed commercial boundary; open core accepted  
**Date:** 2026-11-08

## Context

Reproducibility and trust require public algorithms while customers may value recurring managed workflows.

## Decision

Keep ingestion, inference, assumptions, schemas and evaluation open; sell optional hosting, private integrations, support and SLA only if validated.

## Consequences and alternatives

Licenses remain distinct for code, external data and customer agreements. Alternatives must be revisited when new empirical results or customer requirements justify added complexity.
