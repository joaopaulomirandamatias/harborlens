# Data Governance

Classes: `SYNTHETIC`, `PUBLIC-WITH-TERMS`, `LICENSED-THIRD-PARTY`, `CUSTOMER-CONFIDENTIAL`, `SECURITY-SENSITIVE`.

Only synthetic safe fixtures are permitted in Git by default. Research artifacts must record source, timestamp, rights, SHA-256, coverage and limitations. Dataset licenses do not inherit the code's Apache-2.0 license. Restrict customer/live/licensed datasets to authorized storage/retention. Sensitive claims about identifiable vessel activity require appropriate review. The project is not a navigation, security, enforcement or regulatory certification system.
