# Roadmap and Evidence Gates

| Phase | Deliverable | Release gate |
| --- | --- | --- |
| 0 Foundation | Python CLI, synthetic tests, SDD docs and CI | Synthetic evidence only (baseline) |
| 1 Real data | One official NOAA archive with hash/schema/QA, then consecutive days | Rights and reproducible source/coverage report |
| 2 Facility and validation | USACE geometry, independent labels and error metrics | F1/MAE/unknown share and uncertainty by cohort |
| 3 Environmental scenarios | EPA-aligned modeling with sensitivity | Expert review and no unsupported causal claims |
| 4 User discovery | Interviews and evidence of recurring buyer decisions | Documented feedback, problem cost and budget |
| 5 Paid product | Only justified integrations/hosting | Pilot intent, isolation, commercial data rights and support capability |

No pre-alpha release may imply validated Houston port calls, live tracking, measured emissions, paying customers or U.S. government endorsement.
