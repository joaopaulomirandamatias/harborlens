Schemas are **JSON Schema Draft 2020-12**, versioned by major directory. AIS point, stationary candidate and run manifest represent current prototype formats (CSV must be type-coerced to validate). Source snapshot is a proposed future contract. A new product or API must not claim schema conformance until serialized-output tests pass. Every event currently has confidence=unvalidated.

The SPEC-004 track-zone-evidence and track-zone-context-receipt contracts cover an **unverified geometric observation report**, never independently confirmed anchorage or berth/waiting events. Source receipt hashes are verified locally; authoritative source dates and reuse rights are NOT inferred.

SPEC-004 historical geometry documentary contracts: noaa-enc-documentary-evidence.schema.json and geometry-vintage-audit.schema.json. Both deliberately lack any status that could automatically approve historic polygons or operational maritime events.

The fr-official-text-triage.schema.json contract preserves source hashes and mandatory legal status NOT_DETERMINED for four official Federal Register Part 110 texts; keyword matching does not certify a section amendment or historical anchorage perimeter.

`govinfo-lsa-dec-jan-comparison.schema.json` is the opt-in December 2023 / January 2024 GovInfo LSA index comparison. Each official PDF URL is a const for one fixed HTTPS GovInfo path. `legal_effect_on_study_date` is const `NOT_DETERMINED`, `rights_status` is const `review_required`, and AIS spatial joins stay false. `harborlens_version` is required and records the package version that wrote the file. Each month's PDF SHA-256, byte length, and page count are const pins (December 2023: 117 pages; January 2024: 82 pages). The page count cannot exceed 299 (`MAX_PDF_PAGES`). A matching proposed-rule page list is not a legal determination, a berth, an anchorage, a wait, or a port call. This file lives in `schemas/v1/` with the other research contracts. It is not copied into `src/harborlens/schemas/`. setuptools packages `src/harborlens/schemas/v1/*.json`: the rights register and the three release-gate schemas named below. Other research contracts stay in `schemas/v1/` only.

Serialized-output tests (`tests/test_contracts.py`) validate the real CLI exports: the run manifest as written, `stationary_candidates.csv` read back with `harborlens.ais.read_candidates_csv` (typed `duration_min`, `point_count`, `centroid_lon`, `centroid_lat`, `maximum_distance_m`) against `stationary-candidate.schema.json`, and each single-file GeoJSON Feature against `stationary-candidate-feature.schema.json`. Manifests carry `code_version`; the package version is part of `run_id`.

`release-verification-result.schema.json` is the stdout contract of `harborlens-verify-release`. `verified: true` means the signed aggregate and the pinned rights snapshot matched the supplied trust anchors. It does not certify AIS observations, source rights, anonymity, or a berth, anchorage, wait, or port call.

`harborlens-release-summary` writes a `public-summary-v0.1` file. `public-summary.schema.json` is that staged document. `publication-review.schema.json` is the signed review object inside it. Copies of these three release-gate schemas live at `src/harborlens/schemas/v1/` and are byte-identical to the files in `schemas/v1/`. `read_packaged_release_schema` loads them with `importlib.resources` only. A name outside that allowlist is refused. A schema file next to a virtualenv is not consulted. `reviewed_at_utc` is an RFC3339 UTC date-time. Both commands accept it only when it is not older than 30 days and not more than 5 minutes ahead of the checker clock. The 5 minutes are a fixed clock-skew allowance, not a configuration knob. A date-only value is rejected. These contracts do not approve source rights.

`label-sample.schema.json` is `label-sample-v0.2`. Each key item has `transceiver_class` (`A`, `B`, or `absent_or_unknown`) and a `stratum` whose last component is that class. Candidate keys are `duration|censoring|vessel_group|transceiver_class`; negative keys are `negative|vessel_group|transceiver_class`. `stratification.all_non_empty_strata_drawn` is false when the requested size is smaller than the number of non-empty strata (full cross-cell coverage is then impossible). Per-class coverage is still guaranteed when the request is at least the number of classes present in the frame. `absent_or_unknown` is a real stratum for a missing, blank or other class, not a dropped row. v0.1 manifests do not validate. The annotator CSV is not this schema and does not carry the class.
