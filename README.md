# HarborLens USA

Pre-alpha open-source research software for reproducible AIS stationary-candidate analysis. **Synthetic test data only; not for navigation or operational decision-making.**

This repository is being established using specification-driven development. All scientific conclusions require independent validation against authorized real-world evidence.

See `docs/engineering/spec-driven-development.md`, `docs/requirements/`, `specs/`, and `src/harborlens/` for the development baseline.
